GourAILM (~10.8M parameters)
├── 1. Token Embedding (wte: 65 → 384) + Positional Embedding (wpe: 256 → 384)
├── 2. Dropout (p = 0.2)
├── 3. 6× Transformer Blocks:
│   ├── LayerNorm 1 (Pre-LN, 384)
│   ├── Causal Multi-Head Self-Attention (6 heads, 64 dim/head)
│   │   ├── Q, K, V Projections (384 → 1152)
│   │   ├── Scaled Dot-Product: (Q · K^T) / 8 + Causal Mask
│   │   └── Output Projection (384 → 384) + Residual Highway: x = x + Attn
│   ├── LayerNorm 2 (Pre-LN, 384)
│   └── Feed-Forward MLP (GELU, 4x Expansion):
│       ├── Linear (384 → 1536) → GELU
│       └── Linear (1536 → 384) + Residual Highway: x = x + MLP
├── 4. Final LayerNorm (384)
└── 5. LM Head (384 → 65, Tied with Token Embedding)
